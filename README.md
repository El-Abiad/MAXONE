# MAXONE

A Python implementation of three algorithms to solve the MAXONE problem: **Backtracking, Genetic Algorithm (GA), and Memetic Algorithm (MA).**

The objective is to find a binary chromosome of length `n` that maximizes the number of ones.

## Algorithms
- **Backtracking:** Explores all possible chromosomes.
- **Genetic Algorithm:** Uses selection, crossover, and mutation to evolve solutions.
- **Memetic Algorithm:** Combines genetic operations with local search.
